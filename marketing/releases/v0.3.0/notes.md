## Highlights

### Databases in Docs

Docs now have Notion-style databases. Add custom properties (status, select, date, number, checkbox, URL and more) and show the same rows as a table, board, list, calendar, gallery, timeline or form. Open a row in a side peek, save row templates, link views into pages, import and export CSV and Markdown, and import databases from Notion. (#92, closes #77)

### Import from another Orbit

Move tasks, pages and chats from another Orbit instance: connect with its URL and an API token, or upload an export ZIP. The Import page also lists Notion, Obsidian, CSV, Asana, Linear and Trello. (#89)
